GITHUB REPO MANAGER

Mit GitHub verbinden

GitHub bestätigt deine Anmeldung. Der Zugriff wird erst nach deiner Freigabe erteilt.

GitHub fragt diese Rechte an:
  • repo – eigene öffentliche und private Repositories anzeigen und verwalten
  • delete_repo – Repositories löschen

Diese OAuth-Rechte umfassen alle Repositories, auf die dein Konto Zugriff hat. Die Erweiterung zeigt in ihrer Liste nur Repositories, die deinem Konto gehören. Prüfe auf der GitHub-Freigabeseite den App-Namen, den du selbst bei der Einrichtung vergeben hast.
