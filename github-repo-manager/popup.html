Mit GitHub anmelden

GitHub öffnet die Anmeldung und fragt deine Zustimmung ab. Du musst keinen Personal Access Token erstellen oder einfügen.

Die Client ID ist öffentlich. Die einmalige Einrichtung der OAuth-App steht in der Anleitung.

Welche Rechte fragt GitHub ab?

Die Anmeldung fragt repo für private Repos und delete_repo fürs Löschen ab. GitHub verwaltet das OAuth-Zugriffstoken nach deiner Zustimmung; die Erweiterung speichert es lokal im Browserprofil. Die OAuth-Rechte sind weit gefasst und nicht auf einzelne Repos begrenzt.

Du kannst den Zugriff jederzeit unter GitHub → Settings → Applications widerrufen.

Login-Rechte ändern oder widerrufen

GitHub erteilt der OAuth-App die angefragten Rechte repo und delete_repo. Wenn du den Zugriff widerrufen hast, melde dich erneut an. Der Zugriff lässt sich in GitHub unter Settings → Applications widerrufen.
